# SNSの追加記録

2026年10月25日確認。Xは153件、Instagramは28件、YouTubeのショート動画と短い解説動画は160本を収録。X・Instagramそれぞれ1,000件という目標には未達。

XはGitHubの収集済み150件を再確認し、子育てに関連する141件と追加の12件を掲載した。採用は子育てとの関連性の判断であり、投稿内容の正しさを保証するものではない。本文は公式埋め込みで表示し、独自の全文転載はしない。

Instagramは公開アーカイブの個別記事にある具体的な本文と、元のInstagram個別URLを照合した28件。トモニテ、ストッケ、ピジョンなどの2019〜2023年の投稿を含む。元の投稿日を保持し、新着として日付を変更していない。各投稿の`sourceUrl`から照合元を確認できる。アーカイブ側の本文は確認したが、Instagram側の現在の再生可否と内容の正確性は未確認。

Instagramの27動画は長さ未確認、1動画は1時間のため、いずれもショート動画には数えずInstagram欄に掲載。投稿者の紹介文しか確認できなかった20件と、育児語がタグにしかない2動画は掲載しない。埋め込みの読み込みに失敗しても、元の投稿へのリンクを表示する。

YouTubeの160本は実際のタイトル・説明・確認できた字幕に子育て関連語があり、180秒以下で公開・埋め込み可能な動画。153本のShortsと7本の短い解説動画を分けて表示する。防災・地震・災害・事故対策は、子どもが登場していても除外した。個別の確認日時・長さ・掲載元は`data/social-curation.json`に記録。

投稿の複数ラベルは検索用で、医学的な対象年齢や公的制度の利用資格を保証しない。年齢は投稿に明記された範囲を保存し、不明な場合は推測しない。
