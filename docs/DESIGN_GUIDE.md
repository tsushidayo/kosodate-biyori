# 見た目と言葉の方針

2026年10月25日、たまひよ、西松屋、アカチャンホンポ、サンリオベビー、バースデイの公式サイトを参考に全面更新。

- ホームは親子の写真、目的別の短いメニュー、月齢、買い物、お世話、新着見出しの順。説明文を増やさない。
- 本文16pxを基本に、補足13px前後、見出し24〜46px、比較の単価38px。スマホの入力欄は16px。薄すぎる文字は使わない。
- 白と生成り、淡いピンク・黄色を中心にし、重要なボタンには濃いコーラルを使う。薄い色は面として使い、本文は濃い色。
- 同じカードを続けない。目的別はアイコンのメニュー、月齢は並んだ入口、ニュースは見出しの一覧、SNSは投稿カード、価格は比較カード。
- 標準の日本語ゴシック。写真はテーマに沿って使用し、実在の利用者や医療的な見本とは表記しない。出典は PHOTO_CREDITS.md。
- 動きはボタン・写真・表示の切り替えに限定。自動再生や点滅は使わない。動きを減らす端末設定に対応。
- モバイルでは画面下にホーム・月齢・価格・お世話・保存のメニューを固定する。
- 一覧では長い解説を繰り返さず、詳しい情報や重要な条件は詳細で読めるようにする。価格条件、安全に関わる情報は消さない。
- SNSの反応数には収集日を付ける。個人の体験を育児ガイドの根拠として扱わない。
