# 見た目と言葉の方針

2026年10月25日、たまひよ、西松屋、アカチャンホンポ、サンリオベビー、バースデイの公式サイトを参考に全面更新。

- ホームは親子の写真、目的別の短いメニュー、月齢、買い物、実用ガイド、新着見出しの順。説明文を増やさない。親子を表すオリジナルのロゴと、2色のイラストアイコンを使う。
- 全年齢を初期表示とし、「マイホーム」の表示状態を全ページの上部で確認できるようにする。第1子〜第5子の誕生日と妊娠中の予定日は設定画面へまとめる。きょうだいのどなたかに合えば表示し、全年齢へすぐ戻せるようにする。
- 本文16pxを基本に、補足13px前後、見出し24〜46px、比較の単価38px。スマホの入力欄は16px。薄すぎる文字は使わない。
- 白と生成り、淡いピンク・黄色を中心にし、重要なボタンには濃いコーラルを使う。薄い色は面として使い、本文は濃い色。
- 同じカードを続けない。目的別はアイコンのメニュー、月齢は並んだ入口、ニュースは見出しの一覧、Xは公式投稿、動画はサムネイルと再生ボタン、価格は比較カード。
- 支援は「制度」と「自治体の索引」を分け、都道府県→市区町村、年齢/月齢、内容、キーワードの順で選べるようにする。検索件数と条件クリアを近くに置く。全国の索引件数を、全自治体の制度確認済み件数として見せない。
- 読み物はニュース・コラム・X・Instagram・ショート動画を分ける。複数ラベルのいずれか／すべて、情報元、年齢、検索語を組み合わせ、一覧は12件ずつ表示する。ラベルは重複を認め、内容を具体的な言葉で表す。
- 標準の日本語ゴシック。写真はテーマに沿って使用し、実在の利用者や医療的な見本とは表記しない。出典は PHOTO_CREDITS.md。
- 動きはボタン・写真・表示の切り替えに限定。自動再生や点滅は使わない。動きを減らす端末設定に対応。
- モバイルでは画面下にホーム・月齢・価格・お世話・保存のメニューを固定する。
- 一覧では長い解説を繰り返さず、詳しい情報や重要な条件は詳細で読めるようにする。価格条件、安全に関わる情報は消さない。
- XとInstagramは子育てに関連する体験談・意見も掲載し、内容未確認を明示する。動画は実際に子育て関連語があるものに限り、防災・地震・事故対策は除く。反応数には収集日、記事と動画には公開日を付け、古い投稿を最新扱いしない。個人の体験を育児ガイドの根拠として扱わない。
- Xは公式埋め込みで全文を表示し、読み込めない場合の元リンクを残す。動画プレイヤーは操作してから読み込み、YouTube Shortsと短い解説動画を区別する。検索結果ページは動画カードにしない。
- 長い条件や実用ガイドの手順は詳細で読めるようにする。年齢は確認できた対象条件を使い、不明なものを推測で割り当てない。年齢の記載がない情報を含めるかは利用者が選べるようにする。

- 各お子さまの日付欄は未来の日付も受け付け、出産予定日として妊娠中の情報へ合わせる。予定日が過ぎても出産済みと自動で決めず、誕生日への変更を案内する。

- マイホームには住まい（都道府県・市区町村）と各お子さまの任意の性別を置く。店頭購入・店舗受取・ネット通販・フリマを混ぜず、新品と中古の状態を分かるようにする。

- 読む・見る画面では出産準備、お世話・食事、教育・遊び、グッズ、おでかけ、保育・制度、体験談のテーマから検索できるようにする。地域がある記事には都道府県の絞り込みを用意する。Instagram動画はショート動画へまとめ、画像・カルーセルだけをInstagramタブに表示する。
- 価格比較の買い方はネット通販とフリマ。メーカーと、2店以上で比べられる商品の絞り込みを用意する。検索リンクと確認済みの価格は区別する。
