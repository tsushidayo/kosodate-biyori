# 商品とフリマの追加記録

2026年10月25日確認。従来の58商品はID・価格・販売条件をそのまま保持し、ピジョン公式の180商品と、モデル・色を分けたフリマ4商品を追加。計242商品。

## メーカー公式の商品

公開先は [ピジョン公式オンラインショップ](https://shop.pigeon.co.jp/collections/all)。公開の商品データ3ページから、実在する販売中の商品と代表の1バリエーションを取得した。色違いだけで件数を増やさず、定期購入、売り切れ、入荷待ち、e-Gift、旧部品などを除外した。商品名、メーカー品番、価格、画像、販売先、公開された月齢タグを保存し、長い商品説明や効能の文面は転載していない。

追加180商品のうち46商品は商品自体に送料無料の表示があり、134商品は送料を確定できないため `shipping: null` のまま。後者の商品価格は記録するが、送料込みの安い順には入れない。税込5,500円以上で送料無料という一般案内だけを使って、少額注文の送料を0円とはしていない。

`node scripts/import-pigeon-catalog.mjs input.json output.json --limit=180` で公開データを再調査できる。既存の取込商品は同じバリエーションIDで価格・在庫・送料表示を更新する。`--limit=0` は追加せず既存分の再確認だけを行う。既存商品と名前が一致するものは価格へ自動統合せず、メーカー品番・JAN等の照合を別途行う。

## フリマの個別出品

メルカリの公開個別ページについて、JSON-LDとページ本文の両方で販売中・税込価格・送料込み・状態・モデル・色を確認。9出品を4商品に分けた。

- Ergobaby OMNI Breeze オニキスブラック：4出品
- Ergobaby OMNI Breeze ブラック（出品表記）：2出品
- Ergobaby OMNI Breeze ネイビー（出品表記）：2出品
- BABYBJORN BLISS コットン サンドベージュ：1出品

同じ「ブラック」でも色名・品番が確定しない出品は、オニキスブラックに混ぜていない。OMNI360などの別モデル、破れや補修が必要な抱っこ紐、着払い・送料未確認の出品は価格順位に追加していない。検索結果の古い価格ではなく、取得した個別ページの価格を採用した。

Yahoo!フリマは今回の対象が売り切れまたは404。ラクマにはJSON-LDがInStockでも本文がSOLD OUTの出品があったため、販売中として掲載していない。出品は売れるため、購入前には必ず個別ページの在庫・状態・付属品を確認する。

商品画像は各掲載元の公開画像URLを参照する。第三者の写真を自サイトの撮影写真として扱わない。確認済みの価格でも、中古品の品質や安全性の保証とは表記しない。
