# こそだて日和

妊娠・出産から小学生までの、子育て情報サイト。

- サイト: https://kosodate-biyori.tsushidesuyo.chatgpt.site
- GitHub: https://github.com/tsushidayo/kosodate-biyori

## 主な機能

月齢・年齢別のガイド、チェックリスト、お金・手続き、価格比較、ニュース・コラム、X・Instagramの投稿、ショート動画、検索、保存、LINE共有に対応しています。

- はじめは全年齢を表示。マイホームに住まいと第1子〜第5子の誕生日・出産予定日・任意の性別を登録できます。未来の日付は妊娠中として扱い、誕生日を登録すると、きょうだいのどなたかの年齢に合う情報を表示します。全年齢へも切り替えられます。
- 育児・食事・遊び・学びの実用ガイド50件。手順、用意するもの、注意点、出典を詳細で読めます。
- 全国47都道府県・1,741市区町村の索引。個別制度397件を掲載し、制度を探せる地域は176市区町村。制度は地域・年齢/月齢・支援内容・キーワードで探せます。索引の収録と、各自治体の制度の確認範囲は異なります。制度の詳細は公式資料で確認できたものを掲載し、全自治体の独自制度を網羅した一覧とは扱いません。
- ニュース・コラム・X・Instagram・ショート動画は別のタブで表示。複数ラベルの「いずれか／すべて」、情報元、年齢/月齢、キーワードを組み合わせて絞れます。
- X・Instagramは子育てに関連する体験談や意見も掲載し、内容未確認と分かるように表示。防災・地震・事故対策の動画は除外し、実際のタイトルや説明に子育て関連語のある動画だけを掲載。Xは公式埋め込みで原文を表示し、ショート動画はYouTube・Instagramの公式プレイヤーを一覧で自動表示し、動画の再生は利用者が操作します。読み込めない場合も元の投稿へのリンクを使えます。
- 529商品を検索でき、ネット通販とフリマで比較。確認できた通販価格を掲載し、全商品で共通18通販の比較表を表示。商品代・送料・容量・支払総額・確認日をそろえ、送料未確認の価格も区別して掲載します。メルカリの出品9件も、モデル・色・中古の状態を分けて比較できます。同じ商品・数量・送料・条件で比べ、古い掲載や未確認の価格は順位から除外します。

共有情報と利用者ごとの設定はSitesのD1に保存。大きいSNS一覧は内部で分割保存し、1,000件ずつのX・Instagramも扱えるようにしています。GitHubにはサイトのソースと共有情報だけを保存し、住まい・性別・誕生日・出産予定日・個人の保存記事・秘密は保存しません。サイトは本人限定の公開範囲を維持しています。

## GitHubとサイトの更新

GitHubの `collections/index.json` に載った収集ファイルを `/api/refresh` から読み、`data/social-curation.json` の承認結果を照合します。収集しただけのX投稿は掲載しません。同じ投稿の反応数は収集日時で更新し、承認済みのラベルと年齢情報は維持します。数値は現在の人気順とは扱いません。取得失敗時は既存の確認済みデータを保ちます。

InstagramはinstagramPosts、ショート動画はshortsとして `data/social-curation.json` で管理します。各SNS1,000件以上を目標に追加中で、達成済みの件数としては表示しません。検索結果ページを動画として登録せず、個別URL、公開状態、内容、長さ、埋め込み可否を確認します。YouTube Shortsと自治体などの短い解説動画は区別します。

毎日の更新タスクでGitHubの新着を確認し、サイトへ反映した共有情報を `data/*.json` にも保存します。GitHubへのコードのpushだけでSitesが自動的に再公開されるわけではありません。画面や処理の変更はSitesの保存・公開手順が必要です。

価格の比較は通常購入とまとめ買いを分け、容量・枚数・セット数が同じ候補から、各通販の送料込みの総額が安い1件を選ぶ。Yahoo!ショッピング経由とサンドラッグ公式通販のような別の購入先は同額でも別カードにし、通販名と出店者名を分けて表示する。単品を必要数買う方が安い場合は、確認済みの買い方として計算根拠を残す。Amazonはプライム対象を優先して調べ、未確認の送料や会員向けの条件を通常価格と混同しない。

Amazonは選んだ数量の送料込み価格と実順位を比較欄に表示し、上位10件の外でもカードへ移動できる。別数量の価格を見ると通常購入・まとめ買いも切り替わり、同じ量の他店と比較する。プライム会員向けの送料0円は、価格と同じ購入欄でAmazon発送を確認できた通常配送に適用し、別出品の最低額や発送元不明の価格には適用しない。通常購入と定期便・クーポンの価格は区別し、条件付きの価格は利用者が選んだときだけ順位へ含める。定期便しか確認できない場合も通常額を推測せず、掲載した条件で比較する。

スギ薬局は18通販とは別の店頭欄として比較先に追加。定価・通常価格を元に、選択した量についてクーポン使用時の仮額を試算できる。1品割引は単品1点分に限定し、対象外のベビーミルク等も、割引を使えた場合として仮額を表示し、実際は割引対象外であることを併記する。未確認の全品8%は仮設定、年齢・期限・金額・入手の条件は説明を開いて確認できる。ポイント還元と仮額は実際の価格順位へ混ぜない。

価格比較の追加点検：単品の複数買いとセット売りを、根拠のある送料条件に従って比較する。在庫の確認が曖昧な掲載を順位から除外。巡回時に単品価格が複数点の合計を上書きしないよう、数量と送料の扱いを修正した。スギの試算は確認できた通常価格を初期値とし、参照元を表示。メーカーの定価・スギの店頭価格とは区別する。Amazonはプライム会員を前提に対象のAmazon発送を送料0円で比較し、非会員は通常460〜500円、Amazon発送の商品小計3500円以上は通常無料の案内を併記する。ショート197件はすべて公式iframeを自動表示する。
